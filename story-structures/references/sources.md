# Sources and verification notes

Checked 16 October 2026, Asia/Manila. Definitions are paraphrased, examples are original, and the selection criteria are editorial judgments. This package is not an official product of the framework authors. It does not reproduce their worksheets. A source's promotional claim of universal or commercial effectiveness is not adopted here.

## Framework references

1. Joseph Campbell Foundation, [Joseph Campbell and the Hero’s Journey](https://www.jcf.org/learn/joseph-campbell-heros-journey) and [Separation, Initiation, and Return](https://www.jcf.org/post/separation-initiation-and-return). Supports the three movements and the warning against compulsory motif checklists. Primary institutional commentary on Campbell. The 17 conventional headings were cross-checked against [Monomyth Online’s stage listing](https://monomythonline.com/origins/), a secondary reference. The underlying historical work is Campbell's *The Hero with a Thousand Faces* (1949); no claim is made to have read its entire text during this build.
2. Christopher Vogler, [A Practical Guide excerpt](https://www.mccc.edu/~voorhees/dma135/Vogler_Practical_Guide.pdf), from *The Writer’s Journey*, hosted by Mercer County Community College. Primary authored excerpt supporting the 12-stage list. [Vogler's own account](https://chrisvogler.wordpress.com/2023/11/04/chris-vogler-bio-and-frequently-asked-questions/) describes his adaptation of Campbell for story development. The older writersjourney.com page was inaccessible during verification; the package does not depend on it.
3. Syd Field, [The Paradigm Worksheet introduction](https://sydfield.com/syd_resources/the-paradigm-worksheet/) and [paradigm diagram](https://sydfield.com/paradigm.pdf). Primary official material supporting setup/confrontation/resolution and act-changing plot points. This package describes Three Acts more broadly than Field's screenplay implementation and supplies its own editorial distinctions among incident, crisis and climax.
4. Save the Cat official site, [Beat Sheet Mapper](https://savethecat.com/beat-mapper), supports the 15 beat names and separate film/novel use. [Beat Sheet Palooza](https://savethecat.com/beat-sheets/beat-sheet-palooza), an official screenplay example, illustrates page-based notation and flexible actual placement. Historical reference: Blake Snyder, *Save the Cat!* (2005). The conventional page examples here are historical guidance, not prescribed positions for all scripts.
5. Jessica Brody, [How to Write Your Novel Using the Save the Cat! Beat Sheet](https://www.jessicabrody.com/2020/11/how-to-write-your-novel-using-the-save-the-cat-beat-sheet/) and [official starter kit](https://www.jessicabrody.com/wp-content/uploads/2020/01/Save_the_Cat_Writes_a_Novel_Starter_Kit_v6.pdf). Primary sources supporting the novel adaptation and percentage-based pacing. Reference: *Save the Cat! Writes a Novel* (2018). This package uses concise summaries, not the proprietary worksheet or extended explanations.
6. Randy Ingermanson, [The Snowflake Method for Designing a Novel](https://www.advancedfictionwriting.com/articles/snowflake-method/). Primary explanation of the ten-step development process, including the optional status of scene expansion in step nine. Exact page lengths are examples, not output obligations.
7. Gustav Freytag, [Die Technik des Dramas, chapter two](https://www.gutenberg.org/files/50616/50616-h/50616-h.htm), Project Gutenberg text of a later German edition of the work first published in 1863. Primary text supporting the five parts and three connecting forces. English names in this package are conventional renderings; no lengthy translation is reproduced. The historical model is kept separate from modern classroom simplifications.
8. Dan Wells and colleagues, [Writing Excuses 7.41: Seven-Point Story Structure](https://writingexcuses.com/writing-excuses-7-41-seven-point-story-structure/), including transcript. Primary discussion supporting the seven points, planning from the resolution and Wells's acknowledgement of a role-playing-book source. No unsupported inventor claim is made.
9. Dan Harmon, [Story Structure 101](https://channel101.fandom.com/wiki/Story_Structure_101:_Super_Basic_Shit) and [Story Structure 105: How TV is Different](https://channel101.fandom.com/wiki/Story_Structure_105:_How_TV_is_Different). Author-attributed tutorials preserved on the community-maintained Channel 101 Wiki. Useful primary-authored texts with a hosting caveat: the current pages are editable mirrors, not independently authenticated original manuscripts. Supports the eight-position movement and episodic return. Deterioration and quiet change applications in this package are editorial adaptations.

## Claude packaging

- [Anthropic: How to create custom skills](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills): name and description frontmatter, supporting files and a ZIP containing one skill folder.
- [Anthropic: Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude): code execution/file creation prerequisite and upload through Customize > Skills.
- [Anthropic platform: Agent Skills overview](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview): uppercase SKILL.md, progressive disclosure and lowercase-hyphen name rules.

There are small documentation differences: the consumer help article states a 200-character description maximum, while the platform overview permits 1,024; this package stays below 200. The consumer help uses lowercase skill.md in examples, while platform docs specify SKILL.md; this package uses uppercase SKILL.md. The platform page contains an older consumer UI path; installation instructions follow the dedicated consumer Help Center's Customize > Skills path.

The ZIP's first path segment is story-structures/, containing SKILL.md and references/. No extra wrapper directory, executable scripts, API keys, dependencies or OpenAI-specific metadata are included. Skill content can be pasted into ordinary chat for a manual workflow, but installing a custom Claude skill may require enabling code execution/file creation even though the story workflow itself uses no code.

Verification does not establish successful upload, activation or model behavior inside Claude. Those remain user-side checks.
